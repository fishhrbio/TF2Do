# TF2Do Wiki

TF2Do is a personal planning workspace for biotechnology research and coursework. Use it to capture tasks, organize projects, plan your week, and keep short notes linked to the work.

| Page                                            | What it covers                                                          |
| ----------------------------------------------- | ----------------------------------------------------------------------- |
| [How to Use](How-to-Use.md)                     | Create a project, plan a week, link a note, and use keyboard shortcuts  |
| [Backups and Recovery](Backups-and-Recovery.md) | Export, replace a workspace, and recover the copy from before an import |
| [Architecture](Architecture.md)                 | Application structure, dates, and data format                           |
| [Roadmap](Roadmap.md)                           | The first release and what comes next                                   |
