# How to Use TF2Do

## Capture your first task

1. Open TF2Do. Leave the workspace empty to start your own plan, or choose **Load demo workspace** to try fictional examples.
2. Open **Inbox**, type a task title in **Quick add task**, and press **Enter**. Tasks added in **Today** get today as their planned day. Tasks added in **Inbox**, **Week**, or **Projects** start unscheduled.
3. Open the task by selecting its title. Add a description, status, estimate, priority, or project if it helps. Select **Save task** to apply the changes.

## Plan a week

1. Create a project from **Projects → New project** and give it a name.
2. Open a task and choose the project. Set **Planned day** to the day you intend to work. Use **Due date** for the actual deadline.
3. Open **Week** and use the arrow buttons to browse weeks. Tasks appear on their planned day. Use **Ready to schedule** to find undated tasks and set their planned day.
4. Check **Today** for overdue deadlines and unfinished work from past days. Open the task to reschedule it or change its status. An estimate is the planned number of minutes.

## Keep projects and notes together

- To rename or archive a project, open it and select **Edit project**. In the project list, turn on **Show archived** to find and restore an archived project.
- Add a note from **Notes**, from a project’s **Project note** button, or from **Write linked note** in task details. The **Project** and **Linked task** fields can be changed independently. Note text saves as you type. The title saves when you leave its field.
- Use **Search anything** to find task titles and descriptions or note titles and text. Search includes archived projects and completed tasks.

## Complete, reopen, or undo

Select the circle beside a task to complete it. Turn on **Show completed** in the relevant view or find the task through Search, then reopen it from the row or change its status in task details. If you complete or delete an item by mistake, use **Undo** in the notification while it is visible. Deleting a task keeps linked notes and clears their task link.

## Use the keyboard

| Key                | Action                                                                                  |
| ------------------ | --------------------------------------------------------------------------------------- |
| Tab / Shift+Tab    | Move between controls                                                                   |
| Enter              | Add a task from the quick-add field or activate a focused button                        |
| Ctrl+K / Command+K | Open Search when focus is outside a text field or dialog                                |
| Esc                | Close a dialog. A second press discards unsaved task or project edits after the warning |

The same actions are available through visible controls. For moving to another browser or recovering from an import, see [Backups and Recovery](Backups-and-Recovery.md).
