# Roadmap

## Version 0.1.0

The first milestone covers personal planning with Today, Week, Inbox, Projects, and Notes. It includes IndexedDB storage, search, keyboard controls, and JSON backup and recovery.

## Hosted personal workspace

Add sign-in and durable server storage. Define how local changes synchronize, how users resolve conflicting edits, and what works offline. Validate data separation across accounts and preserve the ability to export.

## Further planning features

Explore recurring tasks, dependencies, reusable planning templates, and optional team sharing. Keep task capture fast and preserve the distinction between planned days and deadlines.
