# Acknowledgements

**TF2Do sole developer and maintainer — Robert Waite** ([fishhrbio](https://github.com/fishhrbio)).

Robert is a biotechnology graduate student at the University of South Florida. TF2Do grew out of the need to organize research and coursework tasks, plan when to work on them, and keep project notes in reach.

Structured, Raycast, ORYZO AI, and Inversa informed the visual references in the original project brief. TF2Do uses its own application code and assets. The references informed choices such as a restrained palette, a clear daily view, and keyboard access to search. [Structured](https://structured.app/) · [Raycast](https://www.raycast.com/)

TF2Do uses React and the browser’s IndexedDB API. Vite, TypeScript, Vitest, fake-indexeddb, Playwright, and Prettier support development and testing. See the [third-party notices](THIRD_PARTY_NOTICES.md) for dependency attribution.
